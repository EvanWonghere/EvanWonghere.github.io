      01 / READ ALOUD

      现在，读这一句

      每段最多 60 词，录音最多 25 秒。读长文时请拆成短句。

      开启后，录音时浏览器会把声音交给它自己的听写服务（Chrome 用 Google，Safari 用 Apple），用来显示读到哪里。本站不接收这段声音。

      评分请求改走 Azure 的 WebSocket 通道（在我们的服务器上进行，浏览器仍只用 HTTPS），多返回每个音素的 IPA 名和“最像是读成了哪个音”。只对美式口音有效；通道不可用时自动改用普通评分，页面会告诉你。

      00:00 / 00:25

      正在准备练习室…

      录音先留在此页面；点击“发送录音并评分”后，音频和朗读文本经本站 Supabase 后端转发至 Azure Speech（东南亚）。本站后端不保存录音，刷新即丢失；文字和成绩保存在此浏览器。
